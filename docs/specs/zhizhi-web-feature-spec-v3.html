知枝 Web · 完整功能树（v3.2）

基于 Pi Agent 全栈 TypeScript Monorepo（对标 DeepSeek Harness 工程门禁） 的 Agent-Native LLM Wiki 多用户知识系统： V1 起即内建多人账号隔离（零 Docker 本地 PGlite 直跑，生产无缝切 PG，V1 去 Redis 依赖）；前端按功能划分为6 个预设情境独立页（零 DOM 逻辑层兼容未来移动端 + PWA）；知识卡强绑定 1:N 多题库（入库默认异步 2 道选择题 + 改卡判重补题）；独立错题页解耦归档；知识雷达锚定地图。

1. V1 直接启用多人账号隔离 提前至 V1

v2：V1 单人免登录仅留 user_id，V2 再做登录与隔离
v3.1：V1 直接内建登录鉴权与严格账号数据隔离（部署到共享服务器）；本地离线/单人使用同样无感支持（单账号即单人）。

2. 知识来源插槽式插件架构 架构升级

v2：内置固定来源处理器
v3.1：所有来源（Git、网页、视频、本地 HTML/PDF/MD、对话）设计为可热插拔的标准插槽（插件/MCP 兼容），便于二开开源项目与独立更新（如 B 站/抖音反爬）。

3. 统一 Markdown 中间层 + AI 子循环 新增层

v2：各来源各自提纯后直通三出口
v3.1：任何原始来源不得直入 Agent 主循环；先经标准化 Schema 校验 + AI 子循环解析表格/图片（图走 OSS/相对路径），产出统一 Standard Markdown 原始资料。

4. Git 采集器总结化、剥离代码片段 语义调整

v2：摘取 10~30 行核心代码内嵌卡片
v3.1：跨端采集器（Win/Mac）内置总结能力，将 Commit 转为架构层抽象的 Markdown 资料；提炼与出题完全脱离原仓库代码片段（必要时由 AI 现编伪代码）。

5. 统一 AI 对话入口 + 技能开关 入口合并

v2：「日常问 AI」与「问自己的知识库」拆为两个独立页面
v3.1：合并为单一问答入口页；通过「生成知识卡」技能开关控制是否出新卡（关闭时仅自然语言问答与旧卡推荐）。

6. Agent 自主查库 + 联网搜索兜底 检索升级

v2：手动开关“顺便参考知识库”，库无记录则止步
v3.1：主循环 Agent 自主判断是否调用知识库检索工具；库内命中则带出处作答，未命中则自动触发联网搜索工具兜底。

7. 知返题型工具化 + 题型开关 工具化

v2：V1 写死三类固定题型流程
v3.1：每种题型封装为独立 Agent Tool；V1 首期优先选择题（单/多选+解析），V1.5 扩展判断题 / 填空题 / 问答题 / 伪代码预测；界面题型开关硬约束模型可调用工具。

8. 预设情境独立页面 + 页内有限动态调整 后半程定稿

v2/初版：单一通用画布或静态多页
v3.1：按功能划分为问答、搜索、知识来源、知识库、知识地图、错题本等独立页面，预设各自情境骨架，仅允许用户与 Agent 在页内动态投放预设卡片并支持「钉住（Pin）」防覆写。

9. 交互记忆与页内状态持久化 新增能力

v2：仅存对话历史与练题历史
v3.1：记忆系统按「用户 × 预设情境页」持久化交互习惯、页内卡片陈列、钉住状态与动态内容，退出重登无缝续接。

10. 题目与知识卡强绑定 + 1:N 多题挂靠 后半程新增

v2：出题临时依附于单次练习记录，无增量覆盖判断
v3.1：独立题库强绑定知识卡并支持多题挂靠；多文档补卡或更新时，AI 对照已有题目与变更 Diff 判断是否已覆盖，未覆盖才增量出新题；复习优先抽未做/错题并支持追加新题。

11. 入库默认异步出 2 道选择题 后半程新增

v2：仅在用户点击练习时才临时出 2~3 题
v3.1：新知识卡保存入库立即返回，后台异步默认生成2 道选择题：① 认知理解题、② 实际情境应用预测题（设置中提供默认开启的全局开关以控成本）。

12. 独立错题页解耦归档 + 雷达锚定地图 后半程新增

v2：错题缺归档/删除生命周期；雷达与地图依赖未显式化
v3.2：单独设立「错题页面」，与入库完全解耦仅作客观记录，支持归档与删除防积压；知识雷达显式基于知识地图识别已掌握节点、定位缺口并推荐下一张待学卡。

13. Pi Agent 全栈 TS 基座 + DSH 工程门禁 基座已落地

前期：技术栈未定，仅作选型建议
v3.2：正式采用 pnpm Monorepo + Hono + React 19 + Pi Agent（pi-agent-core / pi-ai），落地对标 DeepSeek Harness 的 5 条静态门禁、oxlint 与 AGENTS.md；Python 开源解析器通过 MCP 插件槽独立接入。

14. 零 Docker 双驱动 + 零 DOM 移动端演进层 基座已落地

前期：默认依赖 Docker + PostgreSQL + Redis
v3.2：本地零 Docker 默认 PGlite + LocalFs + DB 持久化队列（V1 去 Redis），填环境变量无缝切 PG/OSS/Docker；前端抽离零 DOM 的 @zhizhi/client-core + PWA 移动底栏，为后续手机端（Capacitor / RN）零返工铺路。

02统一 Markdown 中间层与双循环解耦链路

原始来源经「插槽插件 → AI 子循环」统一转为 Standard Markdown，再由主 Agent 循环按开关驱动 Wiki、画布与知返

总链路：插槽来源层 ──▶ 统一 MD 中间层（AI 子循环） ──▶ 主 Agent 循环与动态骨架画布

上游解析层：插槽插件 + AI 子循环 会议定稿

原始输入全部先过子循环转为统一 Schema 的 Markdown，再交给三出口与主循环，防止脏数据污染主上下文。

Git 采集器插件：跨端定期采集本地/远端提交 → 采集器侧或解析子循环先总结去噪 → 输出脱离具体代码的架构级抽象 Markdown。
网页与视频插件（可拆卸）：独立封装抓取、字幕提取与截帧，B 站/抖音等强维护站点可从开源项目二开并独立替换升级。
本地文件插件（HTML/PDF/MD/Word）：解析器 + AI 子循环处理复杂 PDF 表格，图片提取存 OSS/统一相对路径，统一输出标准 Markdown。
统一对话沉淀：在统一 AI 对话中开启「生成知识卡」技能或手动框选几轮精华对话，送入统一出口预览入库。
统一输出契约 ──▶ Standard Markdown（Schema 校验）──▶ ① 仅收藏 ｜ ② 进待学 ｜ ③ 存知识卡

下游交互层：预设情境多页 + 1:N 题库 + 独立错题 完整定稿

按功能分类提供独立情境页（页内受控调整）；知识卡强绑定 1:N 题库，错题页与入库完全解耦。

STEP 1进入对应情境页问答 / 搜索 / 来源 / Wiki / 地图 / 独立错题页各自预设骨架，页内有限动态调整
STEP 2入库双题 / 改卡判重新卡保存异步出 2 选择题（理解 + 情境预测）；补卡先比对已有题再决定增量出题
STEP 3工具化练题与钉住复习优先抽未做/错题，可追加新题；问答页投放预设卡支持右上角「钉住」防覆写
STEP 4解耦错题 & 地图雷达独立错题页纯客观记录并支持归档删除；知识地图状态直接驱动知识雷达推下一张卡

046 组核心边界速查（v3 校准）

所有架构设计与前后端接口开发统一遵守这 6 条核心契约

多人原生，单人兼容 已更新

V1 起步即多人隔离：全表、索引、OSS 路径与会话强制绑定 user_id，V1 即交付登录鉴权与隔离校验，避免后期数据迁移。
本地单人无感：本地部署注册/启用单个账号即可离线使用，零架构分叉。

插槽采集 + 统一 MD 中间层 已更新

可拆卸来源槽：各解析器独立封装（插件/MCP 形态），移除任一插件不影响系统运行。
子循环前置隔离：复杂解析（PDF 表格/图片/Git 总结）在 AI 子循环完成，校验后输出 Standard MD，严禁原始脏数据直入主循环。

Git 剥离代码，保留架构抽象 已更新

采集器总结化：原始 Commit 信息 + 架构级总结转为标准 MD 原始资料，不囤代码快照、不绑原仓库。
出题具公共性：考察架构决策与原理而非语法细节；如需代码题由 AI 现编独立伪代码。

单一对话入口 + 技能/检索路由 已更新

制卡开关：激活「生成知识卡」技能时允许沉淀新卡（仍需预览确认）；未激活时仅自然语言对话 + 推荐旧卡。
自主查库 + 联网：Agent 自主决定查本库（命中必附出处），库内未命中自动触发联网搜索兜底。

强绑定 1:N 题库 + 独立错题页 完整定稿

入库双题 & 改卡判重：新卡保存异步默认出 2 道选择题（认知理解 + 情境应用预测，可设开关）；补卡或更新先比对已有题再增量补题，支持多题挂靠。
工具化与独立错题页：V1 选择题、V1.5 扩充判断/填空/问答；错题页独立存在、与入库解耦仅作客观记录，支持归档与删除。

预设情境多页 + 记忆 + 地图雷达 完整定稿

分页预设情境：按问答、搜索、来源、Wiki、地图、错题分独立页，页内允许用户与 Agent 有限调整预设卡片并支持「钉住」；记忆系统按页保存续接。
地图驱动雷达：知识雷达显式基于知识地图的掌握状态与拓扑缺口，推荐下一张待学知识卡。
